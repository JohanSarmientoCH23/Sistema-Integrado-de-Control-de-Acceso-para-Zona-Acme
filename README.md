SICA (Sistema Integrado de Control de Acceso para Zona Acme)
SICA es una solución de software robusta diseñada para modernizar y automatizar el flujo de entrada y salida del Complejo Empresarial "Zona Acme". El sistema elimina las brechas de seguridad de los registros manuales, ofreciendo un control preciso, eficiente y altamente auditable.

Características Destacadas:

Reconocimiento Biométrico: Ingreso automatizado mediante cámara y comparación de vectores faciales en tiempo real.

Arquitectura Hexagonal & SOLID: Diseño de software limpio, escalable y mantenible desarrollado en Java.

Base de Datos 4FN: Modelo relacional en MySQL rigurosamente normalizado hasta la Cuarta Forma Normal, eliminando dependencias multivaluadas.

Seguridad (RBAC): Control de acceso dinámico basado en roles y permisos granulares.

Trazabilidad Total: Bitácora de auditoría inmutable que registra cada evento crítico e incidente de seguridad.
